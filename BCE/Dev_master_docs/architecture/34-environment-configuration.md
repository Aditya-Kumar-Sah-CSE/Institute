# 34. Environment Variables & Secret Configuration

STATUS: ✅ IMPLEMENTED

## Environment Variable Schema
- `NEXT_PUBLIC_SUPABASE_URL`: Supabase API Endpoint
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Public Anon Key
- `SUPABASE_SERVICE_ROLE_KEY`: Privileged Service Role Key
- `BYOK_ENCRYPTION_KEY`: 32-byte Master AES Key for encrypting user BYOK keys
- `GEMINI_API_KEY`: Platform Fallback Gemini Key
- `GROQ_API_KEY`: Platform Fallback Groq Key
